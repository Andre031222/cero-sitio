Why the code carries no authorship headers

Source files carry no header. Authorship lives in LICENSE and on this page, once, and not repeated in every file. It is consistent with the rest of the project: the code explains itself, without ornament.

02

Where it comes from

Corvo —called LuxCore until version 0.4.0— starts from the code of JxMVC 3.4.0, copied on 1 August 2026. The core is inherited: 54 classes, of which 40 imported nothing from jakarta.* and moved across untouched.

What changes is the execution model. JxMVC is a WAR that needs Tomcat 10.1 or later. Corvo starts on its own, with its own HTTP server and zero external dependencies.

Why it was copied instead of worked on in place

Because JxMVC is frozen: it backs a paper under review, and its measurements were taken on bare metal under controlled conditions. Any change to the framework invalidates those numbers. Its .git was not copied either: its origin points at the paper repository, and one distracted git push would rewrite it. Corvo starts with a history of its own.

Working rule

JxMVC is read-only. Nothing that happens in Corvo propagates back to it.

And the name

Until 0.4.0 the framework was called LuxCore. The name clashed with a PHP framework in the same environment and the two were constantly confused. Corvo means raven —the mark the project already carried— and keeps the «cor» of LuxCore, which in Latin is heart, the same root as core.

Coming from LuxCore, the guide is at Migrating. And there is no rush: Maven artifacts are immutable, so the applications you do not migrate keep working exactly as they did.

03

What state it is in

Corvo is at 0.4.0, and it is worth saying plainly what that means.

State
Test suite1,260 green, on macOS and on Linux, against real PostgreSQL and MySQL
Continuous integrationJDK 21 and 25, on every change
Runtime dependenciesZero
Applications in productionSix, all ours
Published to Maven CentralNot yet — hence the installer
What is not settled

The HTTP parser is young. It is the surface facing the internet and the one that takes the most punishment: until it has miles on it under real traffic and sustained bursts, calling it mature would not be honest.

And the performance figures were measured in Docker Desktop, inside a virtual machine. The conditions were identical for every framework compared, so the comparison is fair; the standalone numbers have to be repeated on bare metal before being quoted anywhere.
